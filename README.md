# Gemini 划词翻译

一个 Windows 上的划词翻译小工具：选中任意文字，按 `Alt+Q`，或者点一下鼠标旁边出现的“译”按钮，就会在鼠标旁边弹出译文。

翻译交给 [Antigravity CLI](https://antigravity.google/docs/cli/overview)（`agy`）里的大模型来做，默认用 Gemini，也可以换成 Antigravity 提供的 Claude 模型。用的是你登录 Antigravity 的 Google 账号的额度，**不需要任何 API Key**。

## 功能

- **中英互译，自动判断方向**：选中的是中文就翻成英文，其他语言翻成中文。
- **单词释义**：只选中一个英文单词时，给出最常用的一到三个释义，比如 `adj. 无处不在的`。
- **两种触发方式**：
  - 快捷键 `Alt+Q`（可以改）
  - “译”按钮：拖选或双击选中文字后，鼠标旁会出现一个小按钮，点一下才翻译。可以在设置里关掉。
- **比较快**：后台常驻一个 `agy` 会话，平时每次翻译大约 1.5～3 秒。
- **设置窗口**：快捷键、模型、字体、字号、翻译规则、开机自启等都能在窗口里改。
- **保留格式**：译文保留原文的换行和列表，代码、变量名、网址保持原样。

## 工作原理

```
选中文字 ──(Alt+Q / 点“译”)──▶ translate.ahk ──本机 HTTP──▶ agy-server.js ──stdin/stdout──▶ agy（常驻会话）──▶ 模型
   ▲                                │
   └──────── 鼠标旁弹窗显示译文 ◀───┘
```

- **`translate.ahk`**（AutoHotkey v2）：负责取词（模拟 `Ctrl+C`，用完会恢复原来的剪贴板）、显示“译”按钮和译文弹窗、设置窗口。它启动时会把后台服务一起拉起来。
- **`agy-server.js`**（Node.js）：一个只监听 `127.0.0.1` 的小服务，需要随机口令才能调用。它让一个 `agy --input-format stream-json` 进程常驻，把翻译请求排队交给它。
  - 这样 `agy` 的启动和账号检查（每次约 4～5 秒）只在开机时做一次。
  - 每 30 条换一个新对话，避免对话历史越积越长。
- **`workspace/.agents/agents/translator/agent.md`**：一个不带任何工具的最简 agent，翻译规则写在它的系统提示里。比 `agy` 的默认 agent 每次少发约 80% 的 token，速度也更稳定。

## 安装

需要 Windows 10/11。

**1. 安装 AutoHotkey v2 和 Node.js**

```powershell
winget install AutoHotkey.AutoHotkey
winget install OpenJS.NodeJS.LTS
```

Node.js 需要装在默认位置 `C:\Program Files\nodejs`。

**2. 安装并登录 Antigravity CLI**

在你自己的 PowerShell 里运行：

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

装好后重新打开终端，运行一次 `agy`，按提示用 Google 账号登录。你的账号需要能使用 Antigravity。如果提示“所在地区不可用”，说明这个 Google 账号注册的地区不受支持，换代理也解决不了。

**3. 下载本项目**

```powershell
git clone https://github.com/coolzifan123/gemini-translator.git
```

**4. 启动**

在文件资源管理器里双击 `translate.ahk`。右下角托盘会出现一个绿色的 **H** 图标，等几秒让后台服务预热完就能用了。

想开机自动启动的话，在设置里勾选“开机自动启动”。

## 使用

| 操作 | 说明 |
|---|---|
| 选中文字，按 `Alt+Q` | 翻译选中的文字 |
| 选中文字，点“译”按钮 | 同上。按钮 4 秒内不点会自动消失 |
| 弹窗里点“复制” | 复制译文 |
| `Esc` 或点别处 | 关闭弹窗 |
| 右键托盘图标 → **设置…**，或双击托盘图标 | 打开设置 |
| 右键托盘图标 → **Exit** | 退出，后台服务也会一起退出 |

## 设置

所有设置都在设置窗口里改，点“保存并应用”后脚本会自动重启生效。你的设置保存在 `config.ini` 里，这个文件不会进 git。

| 标签页 | 设置项 |
|---|---|
| 常规 | 翻译快捷键、模型（点“刷新列表”可以从 `agy` 拉取全部可用模型）、等待超时、弹窗宽度、字体、字号、是否显示“译”按钮、开机自动启动 |
| 翻译规则 | 发给模型的翻译规则，也就是 `agent.md` 的正文。可以改成更口语化、专业术语保留英文等等，也能一键恢复默认 |
| 高级 | 服务端口、每个对话最多翻译多少条、服务端单条超时；另有打开服务日志、打开程序文件夹的按钮 |

**模型怎么选**：`gemini-3.8-flash-low` 很快，日常够用。作者实测 `claude-sonnet-5-5-low` 译文更贴切，速度也差不多，甚至略快。`-medium`、`-high` 和 `pro` 系列更慢，对划词翻译提升不大。

## 隐私

- 选中的文字会发给 Antigravity 背后的模型服务做翻译。
- 本地日志正常情况下只记录调用耗时、字数这类调试信息，不记录原文和译文。翻译出错时，可能会记下 `agy` 返回的错误内容。日志位置：
  - `%TEMP%\gemini-translate\agy-server.log`
  - `%TEMP%\gemini-translate\ahk.log`
- 后台服务只监听本机 `127.0.0.1`，而且每次启动生成一个随机口令，其他程序无法调用。

## 排查问题

- **一直显示“翻译中…”或者翻译失败**：先看 `agy-server.log`，确认里面有 `session ready`，以及有没有报错。
- **提示找不到 `agy.exe`**：确认 `%LOCALAPPDATA%\agy\bin\agy.exe` 存在。如果你是在 Claude 桌面版之类的 MSIX 打包应用里安装的 `agy`，它可能被装进了那个应用的私有目录，外面的程序看不到。在普通终端里重新装一次就行。
- **某些程序里不出现“译”按钮**：按钮只在拖选过程中光标变成过文本输入的“I”形时才会出现。有些程序（比如部分 PDF 阅读器）用的是自定义光标，这时请用 `Alt+Q`。以管理员身份运行的程序里也不会出现，因为普通权限的脚本收不到它的鼠标点击。
- **用了一段时间后“译”按钮不出现了，但 `Alt+Q` 正常**：Windows 停用了脚本的鼠标钩子（电脑很卡或刚睡眠唤醒时可能发生）。脚本每 30 秒、以及每次唤醒后会自动重装一次，一般过一会儿就恢复了；急用的话右键托盘图标 → **Reload Script**。
- **原文里有“忽略之前的所有指令”之类的文字时特别慢**：这是模型服务端额外做了检查，译文本身没问题。

## 已知限制

- 只支持 Windows。
- Node.js 的路径写死为 `C:\Program Files\nodejs\node.exe`。
- 每次翻译还是要 1.5～3 秒，主要花在模型服务端处理和网络往返上。
- 依赖 Antigravity CLI 的 `--input-format stream-json` 模式和自定义 agent 功能。`agy` 更新后如果行为有变化，可能需要调整。
